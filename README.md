#🔐 Simple Login System (Python)
A beginner-friendly command-line login system built using Python.
This project simulates a basic authentication system with limited login attempts.

##🚀 Features:
User login using username and password
Maximum 3 login attempts
Account lock message after failed attempts
Simple and clear CLI interaction

##🛠 Technologies Used:
Python 3

##🧠 Concepts Used:
Variables
Conditional statements
Loops
User input
Basic authentication logic

###▶️ How to Run:
Ensure Python is installed on your system
Clone the repository or download the file
Run the program using:
```bash
python Simple login system.py
